# Reports UI prototype

Provide four interactive, localized reporting screens and attorney details using clearly fictional, deterministic frontend records. Owners/admins may inspect company totals; individuals see a dedicated authenticated demo profile. Preserve the real profitability report and all existing finance behavior.

Shared period/date-basis/entity/status filters, responsive KPI cards, accessible charts, searchable sortable tables and allocation drilldowns derive from one dataset. Collections remain linked to their invoices; work shares and origination allocations are distinct, rounded in minor units. Outstanding is a balance as of the range end, not a difference between unrelated period flows. Collection basis shows payments in the selected interval; work/invoice bases show selected cohorts with collections to the interval end. Missing sharing rules remain visible and are excluded from eligible allocation/distribution totals.

Serbian Latin and English are supported. No backend, migration, payout tracking, production allocations or real financial integration is part of this delivery. The browser mock boundary is replaceable with reporting API projections later; mock fixtures contain no confidential production data.
