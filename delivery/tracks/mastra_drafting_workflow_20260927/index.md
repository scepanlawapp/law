# Mastra Drafting Workflow

Phase 4 of the [Assistant Mastra Migration](../assistant_mastra_migration_20260927/index.md) epic. Lawsuit drafting becomes a Mastra workflow that the `legalAssistant` agent can call as a tool. Drafts can be revised from chat ("skrati drugi pasus"), and the agent sees the drafts that belong to the conversation.
