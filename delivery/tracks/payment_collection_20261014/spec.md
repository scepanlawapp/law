# Payment management and invoice collection

Implement independent manual receipts, editable multi-invoice allocations, advances, unidentified receipts, immutable audit history and controlled voiding. Derive invoice and client balances from active receipts using exact decimals. Reuse finance manager authorization, workspace isolation, invoice lifecycle and mutation idempotency. Serialize allocation mutations with invoice lifecycle changes. Serbian Latin UI uses existing Spartan components, real server filtering/pagination, currency-separated summaries, invoice/client entry points and a visibly unavailable future import button.

No bank import, accounting ledger, automatic allocation, FX conversion, or changes to SEF behavior.
