# Chat Starter Pickers

Let starter cards on a new assistant chat pick a client, case, colleague, or document from a list instead of making the user type it.

- **Status:** completed
- **Scope:** picker dialog for starter cards, grouped general card set, explicit `doc:<id>` reads for the assistant's document tools.
