# Assistant Read Tools

Follow-up to the [Assistant Mastra Migration](../assistant_mastra_migration_20260927/index.md) epic. The `legalAssistant` agent gets read-only tools for office data: clients, case search, tasks/deadlines/events, the agenda, and case/client activity with notes. "Me" is the user who sent the message; colleagues can be looked up by name.
