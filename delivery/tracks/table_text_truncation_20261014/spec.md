# Table text truncation

Keep dashboard cases, case list and client list within the page width even with very long titles, names or contact details. Bound column sizes and show ellipses for long text, preserving complete values in the DOM and native title hints. Retain links to details. On narrow screens, allow horizontal scrolling inside table containers.

Column refinement: case number, priority, status and opened date use 60% of their preceding widths; client type and responsible lawyer use 60%. Freed space goes to case/client names. Compact content must remain contained and complete values available on hover.
