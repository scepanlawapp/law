# Clients and Cases Frontend Specification

Build API-connected Angular workflows for Clients and Cases using the existing authenticated workspace context, Reactive Forms, default Spartan/UI primitives, and SR/EN localization. No custom CSS, inline styles, Tailwind styling utilities, or styling overrides are allowed.

Create/edit uses routed pages. Client and Case details load related collections separately. Destructive operations use the existing confirmation dialog and successful mutations use the existing toast service. Documents, uploads, finance, AI, and future modules are excluded.
