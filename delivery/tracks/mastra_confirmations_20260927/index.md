# Mastra Confirmations

Phase 5 of the [Assistant Mastra Migration](../assistant_mastra_migration_20260927/index.md) epic. The `legalAssistant` agent can propose changes to office records: link the conversation to a case, create a deadline, or create tasks from a brief. Nothing changes until a lawyer approves the proposal in a confirmation card in the chat. After the decision, the agent continues.
