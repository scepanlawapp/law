# Mastra Assistant Slice

Phase 2 of the [Assistant Mastra Migration](../assistant_mastra_migration_20260927/index.md) epic. Legal questions are answered by a multi-turn `legalAssistant` Mastra agent that has read-only tools (legal sources, cases). It runs behind `ASSISTANT_ENGINE=mastra` and streams into the existing chat UI.
